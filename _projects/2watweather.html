🌦️WATWEATHER:

Solo project

A weather app built with JavaScript and the OpenWeatherMap API, featuring city-based weather information with a 5-day forecast, date and time display for selected cities, dark and light modes, dynamic weather icons, a responsive design using CSS media queries, flexbox, and grid, and seamless ℃/℉ temperature conversion.

TECH: HTML, CSS, JavaScript
