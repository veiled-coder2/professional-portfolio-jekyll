🍲Mealy

Team project

A restaurant web application built to ease food delivery to customers with pickup, bulk order and delivery features. Built with REACT.JS, state management with redux toolkit,and css to ensure responsiveness

Role:

  • Served as the team lead, overseeing project development.
  • Implemented and set up Redux Toolkit for state management to synchronize application state across multiple components such as modals, authentication state by defining actions, reducers, and a central store.
  • Integrated authentication APIs such as login, signup, password reset, and user information update (name, email, passwords) using Axios POST and PATCH requests.
  • Developed a variety of modals using React Modal and Portals library, utilizing Redux actions and reducers to control the opening and closing of modals. These included profile edit, email edit, password update, and logout modals.
  • Utilized React Router v6 to implement layout routes, creating reusable layouts for shared components across multiple pages, nested routing, and form actions to optimize the loading strategy of restaurant APIs on render, resulting in reduced load time and delays, improving user experience.

Collaboration:

  • Utilized Agile Methodologies such as Scrum to enhance project development.
  • Conducted regular code reviews, merged pull requests, and resolved code conflicts using Git as version control system.
  • Engaged in daily standup meetings with team members to track project progress and address any blockers faced.
  • Leveraged a project management platform, ClickUp, to assign tasks and monitor deadlines to ensure timely task delivery.

TECH: React, Css
