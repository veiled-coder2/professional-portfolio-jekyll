👩‍💻PORTFOLIO:

Solo project

A static website built with Jekyll to showcase web development skills, featuring a responsive layout, clean design, and reusable components using Jekyll includes for the footer, navigation, and more. It incorporates dark and light themes, is based on a customized version of the Minima theme, and is hosted on GitHub Pages for a seamless user experience.

TECH: HTML, CSS, JavaScript, Jekyll
