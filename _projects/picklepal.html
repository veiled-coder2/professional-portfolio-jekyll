⚾PICKLEPAL:

Team project

picklepals is a Full stack MVP web application built with React that provides a platform for pickle ball enthusiasts at Toronto to connect and schedule matches

Features:

  • Players are matched based on availability, level, and seeking type.
  • Players can view pending invites and invitations.
  • An invited player can accept or reject invitations.
  • Players can also send a mail to schedule matches.
  • Lists of available courts are visible on the website.

Role:

  • Implemented Redux Toolkit for state management to synchronize application state across multiple components such as modals, authentication state by defining actions, reducers, and a central store.
  • Integrated Authentication, invitations, and courts APIs.
  • React Router v6 to implement layout routes to create reusable layouts for shared components across multiple pages, nested routing, and form actions to deliver an optimized loading strategy of restaurant APIs on render, resulting in reduced load time and delay, thereby improving user experience.
  • Implemented responsiveness across all screen sizes.

Collaboration:

  • Agile Methodologies such as Scrum to enhance project development.
  • Engaged in daily stand-up meetings with team members to know project progress and address any blockers faced.
